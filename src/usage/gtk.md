A GTK 3 theme for Inkscape and any other GTK 3 app that follows the system theme.

1. Copy a flavour folder from this folder into `~/.themes/`.
2. Select it as your GTK theme.

It recolours Adwaita rather than replacing it, so the few surfaces Adwaita hardcodes stay
grey. GIMP and darktable ignore the system theme entirely and have their own ports:
[GIMP](../gimp) and [darktable](../darktable).
