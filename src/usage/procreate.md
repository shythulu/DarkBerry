The palette itself, as Procreate swatches: one `.swatches` file per flavour, each a palette
of the flavour's 29 colours in the [GIMP Palette](../gpl)'s order (the accents, then the
neutrals from text down to crust).

1. Get the files onto the iPad with AirDrop, iCloud Drive or Files.
2. In Procreate, tap the colour disc, open the Palettes tab, tap +, then New from File, and
   pick a flavour, such as `Darkberry Mire.swatches`.

In Split View you can also drag a `.swatches` file from Files into the Palettes tab.
Procreate swatches carry no names; the GIMP palette has the same colours, in the same
order, each named.
