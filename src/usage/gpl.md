This is the palette itself, not a theme. It's in the GIMP palette format, which GIMP,
Inkscape, Krita, MyPaint and Aseprite all import. There is one file per flavour, plus
`darkberry.gpl` with all four, every colour labelled with its flavour and name.

- GIMP: Edit > Preferences > Folders > Palettes shows where GIMP looks. Copy the files
  there, or open Windows > Dockable Dialogs > Palettes and import them one at a time.
- Inkscape: copy the files into `~/.config/inkscape/palettes/` and pick them from the
  menu at the left end of the palette bar.
- Krita: Settings > Manage Resources > Import Resources.
