Works in Chrome, Edge and any other Chromium browser.

1. Unzip a flavour's zip from a [release](https://github.com/shythulu/DarkBerry/releases)
   (`darkberry-chrome-mire-<version>.zip`) into a folder you'll keep, or copy its folder from here.
2. Open `chrome://extensions`, turn on Developer mode and use *Load unpacked* on the folder.

If the theme isn't available on the extension store you can install it manually, with caveats. Chromium treats a theme as an extension, so a folder loaded this way stays installed
until you remove it. Don't delete the folder afterwards, or the theme goes with it.
