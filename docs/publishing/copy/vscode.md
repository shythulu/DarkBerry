# Listing copy: Visual Studio Code

Reusable text for the two VS Code extensions, written 2026-10-06. The same words go to
the Visual Studio Marketplace, Open VSX, vscodethemes.com (which copies the Marketplace
description) and the awesome-vscode list, so nothing here names a venue. Facts are from
`src/palette.json`, `src/tints.json` and `STYLE_GUIDE.md`; if the palette changes, change
this file too.

Where each piece goes:

| Piece | Field |
|---|---|
| Name | `displayName` in `package.json`, already set |
| Short description | `description` in `package.json`. One line in search results, so keep it under about 120 characters |
| Long description | the README, which the Marketplace and Open VSX render as the listing page. Drop the paragraphs below under the preview image, before Usage |
| Keywords | `keywords` in `package.json`, shown as tags on the listing |
| One-liner | awesome-vscode entry, tweets, release notes |

Both `package.json` files are generated by `build.mjs`, so the short description and
keywords are edited there (or in the palette file's `description`), not in `ports/`.

## Darkberry (the plain extension)

### One-liner

A bog-witch berry theme in four flavours. Wine-dark plum, soft on the eyes, checked for contrast.

### Short description

Darkberry: a bog-witch berry theme in four flavours, one light and three dark. Wine-dark plum with berry accents.

### Long description

Darkberry is a colour theme in four flavours, built around one dark purple (`#4b3540`).
The dark flavours sit in that colour. The light one keeps a cousin of it for text.

The flavours:

- Wisp, light. A pale pink-grey page with violet-leaning text. The light theme that doesn't hurt.
- Fen, soft dark. The background is within a shade of that purple. Rosy, dusky, the one to read in at night.
- Mire, dark. Wine-dark with berry accents. The main dark flavour.
- Blackwater, darkest. The same accents as Mire on deeper wine surfaces. Blood in bog water.

The accents are fourteen berries: blossom, petal, berry, plum, cranberry, cherry, apricot,
honey, gooseberry, juniper, frost, bilberry, blueberry and lavender. Each one keeps its job
across every flavour, so a string is honey in Wisp and honey in Blackwater.

What's deliberate about it:

- Text reaches 4.5:1 on every background, buttons and focus rings 3:1, and every pair of syntax colours stays a measured distance apart. The build fails if any of that slips, so it doesn't.
- Selections, search hits and diff tints are kept weak enough that code under them stays its own colour.
- The palette follows Catppuccin's shape: twelve neutrals with Catppuccin's names and jobs, the same palette file format and the same terminal colour rules. If you know your way around a Catppuccin port, you know your way around this one.
- The same palette file generates themes for Neovim, Kate, kitty, Ghostty, Alacritty, tmux, Firefox, Chrome, Obsidian, KDE Plasma and a dozen more, so your terminal can match your editor.

Works in VS Code, Cursor, VSCodium and Windsurf. Pick a flavour with Ctrl+K Ctrl+T.

If you want the backgrounds in another colour, the "Darkberry with tints" extension carries
four more: Lingonberry, Cloudberry, Crowberry and Blueberry.

### Keywords

theme, dark, light, berry, plum, wine

(What `package.json` already carries. Leave it.)

## Darkberry with tints (the second extension)

### One-liner

Darkberry in five colours of dark. Same berries, five rooms to keep them in.

### Short description

Darkberry's four flavours in five tints: plum, raspberry, peach, violet and slate blue. Twenty themes.

### Long description

This is Darkberry with four more tints beside the plum original, twenty themes in all.
Install it instead of the plain Darkberry extension, not beside it, or the four Darkberry
themes show up twice in the picker.

A tint changes the room, not the furniture. The backgrounds, panels, greys and text shift
toward another berry. The fourteen accents stay exactly where they are, so a keyword is the
same colour in every tint and switching tints never changes how your code reads. Each tint
comes in all four flavours: Wisp (light), Fen (soft dark), Mire (dark) and Blackwater
(darkest).

- Darkberry. The default. Wine-dark plum.
- Lingonberry. Backgrounds steeped in raspberry red.
- Cloudberry. Backgrounds warmed toward ripe peach.
- Crowberry. Backgrounds cooled to inky violet.
- Blueberry. Backgrounds cooled to a dusty slate blue.

Every tint passes the same checks as the original: text at 4.5:1, controls at 3:1, syntax
colours kept apart, and the build refuses to ship a tint that fails.

Then the Darkberry long description from "The accents are fourteen berries" onward, minus
its last paragraph.

### Keywords

theme, dark, light, berry, tints

## The tints, one at a time

The tints are not separate products. They ship together in the Darkberry with tints
extension, and every line below says so, because a tint name on its own (Cloudberry,
Crowberry) tells a stranger nothing. Each block is a one-liner, a short description and a
paragraph, for a heading inside the with-tints listing, a release note, a screenshot
caption or a post about that tint. The short descriptions also replace the "Tint: X"
suffix in `src/variants/<tint>.json`.

### Darkberry

One-liner: Darkberry's default tint. Wine-dark plum.

Short: Darkberry: a bog-witch berry theme in four flavours. Wine-dark plum with berry accents. The default tint.

Dark purple with the lights down. The dark flavours sit inside the one purple, Mire a
little below it and Blackwater further down, and Wisp lifts it to a pale pink-grey with
that purple kept for text. This is the default tint, the one the plain
Darkberry extension ships on its own, and the one the other four tints are measured
against.

### Lingonberry

One-liner: Lingonberry, the Darkberry tint steeped in raspberry. The warm red one.

Short: Lingonberry is Darkberry with its backgrounds steeped in raspberry red. Same four flavours, same berry accents. Ships in Darkberry with tints.

Lingonberry is Darkberry's plum pushed toward red until the backgrounds read as dark raspberry. It is the
smallest move from the original, about twenty degrees of hue, so it still feels like
Darkberry, only warmer. Fen is the rosiest flavour in the set and Blackwater goes the
colour of dried blood. The cool accents (juniper, frost, bilberry) stand up more against a
red backdrop than they do on plum.

### Cloudberry

One-liner: Cloudberry, the Darkberry tint warmed to peach. Amber lamplight instead of wine.

Short: Cloudberry is Darkberry with its backgrounds warmed toward ripe peach. Same four flavours, same berry accents. Ships in Darkberry with tints.

Cloudberry is the furthest the Darkberry tints go from purple. Backgrounds move to a brown-orange that reads like
a lamp left on in the next room, and Wisp becomes a warm cream page. Apricot is the one
accent nudged here, because it would otherwise vanish into the background. Pick this one
if purple-tinted dark themes have never quite sat right with you.

### Crowberry

One-liner: Crowberry, the Darkberry tint cooled to inky violet. The deep end of purple.

Short: Crowberry is Darkberry with its backgrounds cooled to inky violet. Same four flavours, same berry accents. Ships in Darkberry with tints.

Crowberry is Darkberry's purple with the red taken out. The backgrounds move toward blue and come out
indigo-violet rather than wine, and Wisp is a faint lavender page. It still reads as a
purple theme, which Blueberry does not, so this is the one for people who liked Darkberry
but wanted it cooler.

### Blueberry

One-liner: Blueberry, the Darkberry tint on dusty slate blue. The cool, quiet one.

Short: Blueberry is Darkberry with its backgrounds cooled to a dusty slate blue. Same four flavours, same berry accents. Ships in Darkberry with tints.

Blueberry puts Darkberry's berry accents on slate blue backgrounds, so they sit warm on top,
and the plums and pinks read hotter than they do anywhere else in the set. Wisp becomes a
blue-white page like good paper. If you are coming from a blue-grey theme (Nord, One Dark,
the default Dark Modern) and want the berries without the purple, start here.
