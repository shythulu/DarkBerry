## Usage

1. Copy a flavour from this folder over `~/.config/borders/bordersrc`.
2. Restart borders: `brew services restart borders`.

The focused window's border follows `ui.border.active`, the accent, and every other window
`ui.border.inactive`. Width, style and hidpi are plain defaults in the file; only the two
colours are the theme.
